# Layer compositing (0.4.1)

`compositeRasterPixel(source, backdrop, mode, opacity, noiseKey)` accepts straight ARGB32 and returns straight ARGB32. RGB arithmetic uses encoded channels, without an ICC or linear-light conversion. Source-over weights the source-only, overlapping and backdrop-only portions independently; a transparent backdrop never darkens a Multiply layer. Zero output alpha has canonical zero RGB. DestinationOut remains available as an erasing operator.

Pixel-layer modes are Normal (`SourceOver`), Dissolve, Darken, Multiply, ColorBurn, LinearBurn, DarkerColor, Lighten, Screen, ColorDodge, LinearDodge, LighterColor, Overlay, SoftLight, HardLight, VividLight, LinearLight, PinLight, HardMix, Difference, Exclusion, Subtract, Divide, Hue, Saturation, Color and Luminosity. Existing enum values are preserved. Nonseparable modes use the W3C luminosity and saturation operations; DarkerColor/LighterColor select a complete RGB triple by channel sum. Dissolve hashes the caller-provided coordinate key, produces binary source coverage, and is repeatable. Callers rendering regions must supply stable document-coordinate keys.

The alpha and separable/nonseparable definitions follow [W3C Compositing and Blending](https://www.w3.org/TR/compositing-1/). Hard Mix uses the [Adobe channel-sum rule](https://helpx.adobe.com/photoshop/desktop/repair-retouch/adjust-light-tone/blending-mode-descriptions.html): sums at least 255 produce 255, including equality. All 65,536 channel pairs are tested. The remaining arithmetic modes implement documented RGB operations; exact Photoshop color-managed, 16-bit, HDR and special Fill-slider arithmetic is not claimed. The layer API does not extend the brush stroke blend-mode subset.

`compositeLayerStack` renders contiguous clipping chains against their base shape, including its pixel mask. Clipped layers cannot pick up opacity from unrelated background layers. Children blend within that shape without increasing its alpha; base opacity and mode are applied to the completed chain. A hidden base suppresses its clipped children, and an orphan clipped layer contributes nothing. Nested pixel groups retain their isolated child composition.

`LayerBlendModesTest` checks all 27 modes over transparent backdrops, reference arithmetic, endpoint ordering, nonseparable results, partial-alpha overlap and deterministic Dissolve. `LayerCompositingContractTest` checks masks, groups and clipping. This is CPU pixel evidence, not GPU shader or Photoshop GUI parity.
