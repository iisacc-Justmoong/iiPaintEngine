# 비트맵 파일 입출력 경계

iiPaintEngine은 BMP·GIF·HDR·JPEG·PIC·PNG·PNM·PSD·TGA 등 기존 비트맵 코덱과
픽셀 편집 기능을 유지하면서 다른 SDK에 대한 빌드·공개 타입·라이브러리 연결을
요구하지 않는다. 코덱은 입력 바이트를 디코딩하고 출력 바이트를 인코딩하며,
파일 읽기와 게시의 실제 구현은 앱이 제공하는 `BitmapFileIO`가 소유한다.

## 앱 연결

`BitmapFileIO::read(path, maximumBytes)`는 제한 이내의 완전한 바이트 또는 오류를
반환한다. `write(path, bytes)`가 성공할 때는 전체 바이트가 게시되어야 하고 실패할
때는 이전 파일을 보존해야 한다. 쓰기 뷰의 수명은 호출이 끝날 때까지이며 구현은
이를 장기간 보관하지 않는다. 각 `BitmapFile` 또는 `BitmapPaintSession`은 주입된
`shared_ptr<BitmapFileIO>`를 보유하고, 새 파일 후보·열기 후보에도 같은 포트를
전달한다. 포트의 동시성 정책은 구현체가 책임진다. 이 C++ 인터페이스를 공유
라이브러리 경계에서 쓸 때 앱과 엔진은 호환되는 컴파일러 ABI 및 C++ 런타임을
사용해야 하며, 서로 다른 ABI 간의 안정적인 C 플러그인 계약은 제공하지 않는다.

기본 생성자는 제공자 없이 유효하지만 파일 생성·열기·저장은 실패한다. 기존 경로
기반 호출자는 포트를 제공하도록 소스를 이행하고 엔진과 앱을 함께 다시 빌드해야
한다. 이 변경은 API·ABI를 바꾸며 이전 바이너리와 새 헤더를 섞어서는 안 된다.
파일을 성공적으로 읽거나 게시한 뒤에만 경로·픽셀·수정 상태를 교체한다. 포트의
오류·예외, 잘못된 입력, 인코딩 실패는 열린 문서의 상태를 보존한다.

독립적으로 구성하는 `Example/FileProvider`는 iiFileProvider Native의 제한된 읽기와
원자적 `File::write`를 연결한다. 제공자는 게시 후 상세 정보와 프리뷰를 비동기
대기열에 넣는다. 대기열 등록이 즉시 프리뷰 완성을 뜻하지는 않는다. 앱은 자체
저장소나 원격 파일 서비스에 같은 인터페이스를 구현할 수 있으며 파일 생성과 메타데이터
정책을 해당 제공자에게 남긴다. 파일 제공자 어댑터는 엔진 기본 패키지에 포함·링크되지 않는다.

별도 어댑터를 설치한 소비자는 `find_package(iiPaintEngineFileProvider CONFIG REQUIRED)`로
찾고 `iiPaintEngine::FileProvider` 타깃을 연결하며 `<FileProviderBitmapIO.h>`를
포함한다. 이 패키지는 앱 측 조합물로 두 SDK를 각각 찾는다.

## 검증

`iiPaintEngineBitmapIOContract`는 저장소가 없을 때의 실패, 제한 전달, 성공적인
PNG 왕복, 쓰기 거부와 읽기·쓰기 예외, 기존 파일·픽셀·수정 상태 보존, 세션의
포트 수명을 검사한다. 기존 비트맵과 브러시 계약은 메모리 저장소로 검사한다.
별도 파일 제공자 소비자는 실제 파일의 원자적 게시·오류 보존과 프리뷰를 검사한다.
설치 소비자는 다른 SDK 탐색을 비활성화한 상태로 컴파일해 별도로 확인한다.

2026-10-28 macOS arm64 검증에서 파일 제공자 탐색을 비활성화한 엔진 빌드의
60개 검사 중 59개가 최초 통과했다. 나머지 예제 경계 검사는 분리된 소비자
디렉터리의 대소문자 경계를 수정한 후 기존 제한 시간으로 다시 실행해 통과했다.
파일 제공자 조합과 별도 설치한 어댑터의 소비자 검사는 각각 1개씩 통과했다.
세 비트맵 예제는 컴파일했으며 실행하지 않았다. 설치는 빌드 디렉터리 안의
검증용 prefix에만 수행했다. Windows·Linux에서의 빌드와 실행은 확인하지 않았다.

파일 제공자 조합 검사의 최초 실행은 새 헤더와 기존 전역 엔진 dylib가 혼합되어
비정상 종료됐다. 검사에서 `DYLD_LIBRARY_PATH` 및 유사한 런타임 검색 환경을
비워 CMake가 선택한 패키지의 라이브러리를 로드하도록 변경한 뒤 통과했다.
이전 설치본의 앱은 새 헤더와 기존 바이너리를 혼합하지 않도록 함께 이행해야 한다.
